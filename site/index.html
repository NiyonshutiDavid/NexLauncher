Run every project in one click.

NexLauncher finds the apps in your projects folder and runs them, with git, a terminal and AI agents built in.

Download View on GitHub

Reads the manifest, not the folder name. These and more run out of the box.

Everything a project needs, in one window.

Open a project and it's ready: run it, read its logs, commit, open a terminal or hand a task to an agent.

One click to run

Frontend, backend or both, Flutter, Docker or the app itself. Live logs and ports, and a setup step when dependencies are missing.

Git without leaving the app

Set your name, stage, commit, pull and push, switch branches and read history. It uses the credentials you already have.

Simulators and emulators

Launch an iOS simulator or an Android emulator, then run your Flutter app on it.

A terminal anywhere

Open a real shell in any project or folder, in a tab of its own.

Menu bar and widgets

Running services, pinned projects and open tasks without opening the app. Press ⌃⌥⌘L from anywhere.

Hand a task to an AI agent, right from the project.

Ask AI opens beside the project you're in. Describe the job, pick how much the agent may do on its own and follow its progress as it works.

Up and running in a minute.

Choose your projects folder

NexLauncher scans it, finds each app and groups folders that hold several.

Press Run

It installs what's missing if you agree, starts the right command and shows the logs.

Hand off the rest
